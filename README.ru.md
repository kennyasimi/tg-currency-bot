# Ratez Bot — Телеграм-бот для конвертации валют

Ratez Bot — это Телеграм-бот, написанный на Python, который позволяет пользователям конвертировать валюты, используя актуальные обменные курсы через внешний API.

Бот поддерживает:
- Пошаговую конвертацию с помощью команды `/convert`
- Быструю конвертацию вида `100 USD to EUR`
- Популярные валюты через пользовательскую клавиатуру

---

## Структура проекта

Проект имеет модульную структуру с четким разделением ответственности:

```
bot/
├── config/ # Конфигурация (токен, константы)
├── handlers/ # Обработчики команд, сообщений и диалогов
├── services/ # Внешние сервисы (API обменных курсов)
├── utils/ # Утилиты (клавиатуры, логирование)
└── main.py # Точка входа приложения
```

---

## Как запустить

Создайте и активируйте виртуальное окружение

Установите зависимости:
```bash
pip install -r requirements.txt
```

Укажите токен бота в файле .env
``` python
BOT_TOKEN=your_token_here
```

Запустите бота
```
python bot/main.py
```

## CI & Качество кода
В проекте используется GitHub Actions с линтером ruff для автоматической проверки качества кода при каждом push и pull request.

Каталог .venv и переменные окружения исключены из системы контроля версий
